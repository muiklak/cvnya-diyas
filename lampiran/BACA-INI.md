# 📂 Folder Lampiran — Surat Lamaran Formal Diyas

## Cara Pakai

Taruh 1 file surat lamaran formal kamu di folder ini.

### File yang didukung:
| Format | Nama file yang harus dipakai |
|--------|-------------------------------|
| HTML   | `surat-lamaran.html`          |
| PDF    | `surat-lamaran.pdf`           |

> **Penting:** Nama file HARUS persis seperti di atas agar otomatis terbaca.
> - Jika kamu pakai PDF  → rename jadi `surat-lamaran.pdf`
> - Jika kamu pakai HTML → rename jadi `surat-lamaran.html`

## Struktur Folder
```
D:\cv diyas\
├── index.html              ← Website CV utama
├── style.css
├── script.js
└── lampiran\
    ├── BACA-INI.md         ← Panduan ini
    └── surat-lamaran.html  ← TARUH FILE KAMU DI SINI
```

---
Setelah file ditaruh, refresh browser → tab "Lampiran" otomatis tampil surat kamu.
