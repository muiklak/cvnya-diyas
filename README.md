# ⚡ Dokumen Lamaran Head of NOC (PT VTNET) & CV - Diyas

Paket aplikasi lamaran pekerjaan interaktif yang memadukan **Lampiran Surat Lamaran Resmi** yang ditujukan khusus kepada **PT VTNET** untuk posisi **Head of NOC (Network Operations Center)** serta **Curriculum Vitae (CV) Modern Eksekutif**.

---

## 🚀 Ringkasan Pembaruan Terkini:

1. **Lampiran Surat Lamaran Resmi (Target: PT VTNET &bull; Head of NOC)**:
   - Dibuat dengan format surat resmi standar korporat (kop nama, alamat, perihal, isi terstruktur, bullet point kualifikasi, penutup, dan tanda tangan resmi).
   - Menyoroti kualifikasi teknis **Setting & Troubleshooting ONT (Optical Network Terminal)** pada jaringan fiber optik, keunggulan **Sertifikasi Paham AI** untuk sistem automasi monitoring NOC 24/7, serta rekam jejak kepemimpinan sebagai **Mantan Wakil Ketua OSIS SMKN Batujaya** dan prestasi akademik **Ranking 1 berturut-turut**.

2. **Fitur Auto-Print**:
   - Begitu halaman dibuka di browser dan seluruh aset selesai dimuat (delay 1.2 detik), sistem akan **otomatis membuka jendela dialog cetak / Simpan ke PDF**.
   - Dilengkapi aturan `@media print` A4 resmi: Halaman 1 mencetak **Lampiran Surat Lamaran**, dan Halaman 2 mencetak **Curriculum Vitae** secara berurutan dan bersih tanpa background gelap.

3. **Penghapusan Mode SFX**:
   - Tombol audio SFX di navigasi atas telah dihapus sesuai instruksi agar tampilan bar atas semakin bersih dan profesional.

4. **Navigasi Dual-Tab Interaktif**:
   - Tab 1: **Lampiran Surat (PT VTNET)**
   - Tab 2: **Curriculum Vitae (Diyas)**

---

## 📁 Struktur File di `D:\cv diyas\`

```text
D:\cv diyas\
├── index.html     # Dokumen utama (Surat Lamaran PT VTNET & CV)
├── style.css      # Desain Glassmorphism, 3D tilt, liquid shimmer, tab switcher & print CSS A4
├── script.js      # Auto-print engine, dynamic spotlight, animated counters, liquid bars & copy email
└── README.md      # Panduan dan informasi dokumen
```

---

## 🖥️ Cara Menggunakan:
1. Buka File Explorer di Windows, lalu masuk ke folder: **`D:\cv diyas\`**.
2. **Klik 2x pada file `index.html`**.
3. Dialog cetak (print) akan otomatis muncul. Anda bisa langsung memilih printer fisik atau memilih **"Save as PDF"** untuk menyimpannya sebagai berkas PDF resmi siap kirim ke PT VTNET!
